# Security policy

## Supported version

Security fixes are applied to the current `master` branch and the currently deployed release.

## Reporting a vulnerability

Please email `awaisshaikhcs786@gmail.com` with the subject `ApplyWise security report`. Include the affected page or feature, reproduction steps, impact, and any safe supporting evidence. Do not include passwords, authentication codes, private resumes, or another user's personal data.

Please avoid destructive testing, privacy violations, automated high-volume traffic, or public disclosure while a report is being investigated. Receipt should be acknowledged within three business days, followed by a status update after initial triage.
